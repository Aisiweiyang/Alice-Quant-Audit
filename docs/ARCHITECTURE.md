# 架构与 Alice 的关系

输入 → 数据检查 → 内置回测 → 成本/参数/分段诊断 → 证据汇总 → 离线报告。
`commercial_mvp.py` 与 `commercial_web.py` 共用 `commercial/` 管线。
`run_metadata.py` 保存运行身份、配置与产物指纹。

公开版从历史 Alice Framework V4 审计原型提取，发布版本独立编号为 0.1.0。
保留必要的研究、账户与测试模块，不携带 V1–V8 的其他代码、运行环境、历史数据
和私有 Git 历史。不是当前 Alice V8 的认证插件或升级版本。

未来接入 Alice 应通过显式适配器读取当前实验、净值、成交和证据清单，
复用当前账户核算；不能默默用本仓库的旧执行器替换当前系统。
报告模板与检查流程可以复用，但数据准入规则、执行假设和指标口径必须重新对齐。
