## 可复现性处理

固定种子合成数据与旧演示缓存逐表比较，逻辑 SHA-256 一致：
`e6a3b4773fbb9d2138cf3dbea2b3474442d5fbc9d2d671db8d59e74b7695db5f`。
不同 pandas 版本会产生不同 pickle 字节，黄金测试因此改用规范化表格内容指纹。
报告仍保存输入文件本身的原始字节哈希。独立比对确认其余黄金指标和结构未变。

首次受限环境运行发现本机 HTTP 和硬链接被拒绝，另有依赖安装尚未结束造成
的 provider 导入问题；依赖安装完成后，在正常本机权限下完整重跑通过。
这不是将失败测试改为跳过。公开版不依赖原项目的虚拟环境或共享 `.deps`。
